# Winning Spirit Cyber Academy

Winning Spirit Cyber Academy is a static informational website focused on account recovery, account protection, and scam awareness for popular social media platforms, developed under the leadership of Elias Leonard Masudi and Winning Spirit Group.

## What is included

The project currently contains the following pages:

- `index.html` — landing page and quick access to guidance
- `recover.html` — step-by-step recovery advice for hacked accounts
- `protect.html` — account safety checklist and security best practices
- `scams.html` — common scam patterns and prevention steps
- `kuhusu.html` — project background and mission
- `style.css` — shared styling for all pages

## Tech stack

This project is intentionally simple and does not use a framework or backend. It is built with:

- HTML for page structure
- CSS for layout and visual styling

There are no JavaScript modules, build tools, or exported functions in the current codebase.

## Run locally

From the project folder, you can open `index.html` directly in a browser, or serve it locally:

```bash
cd "Akaunti-Salama-Website"
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to GitHub Pages

This site is ready for GitHub Pages deployment. Upload the project files to a repository and configure Pages to publish from the root folder of the default branch.

For a step-by-step guide, see `README-GITHUB-PAGES.md` in the parent folder.

## Notes

- The site is an educational resource and not an official support channel for Meta, Instagram, Facebook, WhatsApp, TikTok, or X.
- All links to help pages in the site should be treated as public platform support pages and verified by the user before use.
